# Dipendenze tecniche CityGML (XSD)

Qui gli script scaricano soltanto gli XSD esterni mancanti (GML 3.2.1,
XLink, ISO 19139 e altri import XML), conservando la struttura dell'URL.
Nessun file originale viene modificato. In assenza di rete, il catalogo resta
navigabile e segnala le definizioni esterne irrisolte.
